# Definition

ИНСТРУМЕНТ:

    у него есть права в файловой системе на CRUD для файлов
    - create (путь для чистовика): он создает новый проект с локальным git-ом под названием черновик
        по пути: ~/путь_для_чистовика/черновик/
    - CRUD:
       - для любого переданного буффера мы смотрим на тип файла
            для типа файла Х:
                мы выполняем код обертывания перед сохранением 
                    пример:
       - на каждую новую операцию он делает небольшой коммит в этом гите
    - execute: вызывает произвольную команду порождая новый процесс через process.execute
        - пишет в debug.info stdout
    - finish
        -  для ~/путь_для_чистовика/черновик/** синхрозируй все в ~/путь_для_чистовика/чистовик


## system design

```mermaid
sequenceDiagram
    User->>Agent: Пишем сайт на C
    Agent->>Файловая система: Создать проект сайт /projects/site
    Agent->>+Инструмент: Создание нового проекта сайт
    Инструмент->>+Файловая система: Создает в /tmp/projects/site
    Инструмент->>+Система: запускает демона синхронизации проекта
    Система->>+Файловая система: Отслеживает операции изменения файлов в /projects/site и дублирует их в /tmp/projects/site
    Agent->>+Файловая система: Добавить новый файлик site.c в /projects/site
    Система->>+Файловая система: Вызвать вкладыватель кода для файла site.c перед сохранением в /tmp/projects/site 
    Agent->>Система: Запустить черновик кода из /tmp/projects/site/site.c
    Инструмент->>Файловая система: чистит /tmp/projects/site
```
