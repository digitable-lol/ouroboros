# Как это выглядит

Три страницы с настоящим выводом, без сокращений:

- [Запись трассы](trace-record.md) — файл `debug.info` целиком и разбор каждого
  ключа.
- [Сводка по записям](extraction-report.md) — что печатают `trace-stats` и
  `trace`, полностью.
- [Настройка](configuration.md) — сервер MCP, переменные среды, что нужно
  поставить.

Всё показанное на них — вывод прогонов на обычной машине с Linux (Python
3.12.13, Node 26.7.0, gcc 15.2.0). Ничего не переписано «для красоты»: если в
выводе стоит `ci: -1` или пустой `cpus`, значит так и было.

Короткий сквозной пример — четыре шага от установки до прочитанной записи — в
[README хранилища](https://github.com/digitable-lol/ouroboros#четыре-шага).
