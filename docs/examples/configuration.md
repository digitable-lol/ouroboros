# Настройка

## Подключение сервера

Дословно из навыка:

```json
{ "mcpServers": { "ouroboros": {
    "type": "stdio", "command": "uv",
    "args": ["run", "--directory", "<path>/ouroboros-src", "ouroboros-mcp-router"] } } }
```

Разбор:

| поле | что значит |
|---|---|
| `mcpServers` | список внешних инструментов, которые агент вправе звать |
| `ouroboros` | имя, под которым он будет виден агенту |
| `"type": "stdio"` | разговор идёт через обычный ввод-вывод запущенного процесса |
| `"command": "uv"` | чем запускать |
| `--directory <path>/ouroboros-src` | где лежит сервер; `<path>` подставляете свой |
| `ouroboros-mcp-router` | что именно запускается |

Куда положить этот кусок — зависит от вашего агента: у каждого своё место для
настроек внешних инструментов, и навык его не называет. Обычные места у
распространённых клиентов перечислены на странице [Установка](../install.md).

## Переменные среды

| переменная | что делает |
|---|---|
| `OUROBOROS_DEBUG_INFO` | путь к файлу записей `debug.info` |

*По контракту логгера:* путь берётся из этой переменной, а **если она не задана —
пишется в `./debug.info` в рабочем каталоге процесса**. Операция `execute`
подставляет её равной `<черновик>/debug.info` перед запуском, поэтому обмазанный
код на любом из языков пишет в один и тот же файл.

Других переменных не называет ни навык, ни контракт.

> `FLANG_WATCH` и `FLANG_PULSE` из страницы [Языки](../languages.md) — это
> переменные исполняющей машины flang, а не уробороса. К обмазке они отношения
> не имеют.

## Что нужно поставить

| нужно | когда |
|---|---|
| Python 3.12 или новее | всегда |
| `libclang` | только для C и C++ |
| Node | только для JavaScript и TypeScript |

Отдельной службы серверу не нужно.

## Что настраивается в самой добыче

Из доводов операций навык называет один: **`param_names`** — список имён доводов
для языков, где подпись не читается (TypeScript, C; про C++ и Elixir не сказано
ничего). Без него все вызовы такой функции будут отброшены с причиной
`no-parameter-name`.

Остальные доводы операций в навыке не перечислены. Их читают со стороны самого
сервера — `ouroboros_describe` на нужной группе операций. Это не обход
документации, а предписанный порядок: **вызывать операцию, описания которой не
прочли, нельзя**.
